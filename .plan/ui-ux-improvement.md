# Plan: UI/UX Improvement — GYM Tracker SaaS

## Analysis (UI/UX Pro Max Rules for Fitness/Health SaaS)

### Product Category: Fitness Tracker SaaS
- **Recommended Style:** Dark OLED + High Energy Accent
- **Color Mood:** Energetic, motivational, premium dark
- **Typography:** Bold headlines + clean body (already good: Bebas Neue + DM Sans)
- **Pattern:** Feature-Rich Dashboard + Conversion-Optimized onboarding

### What Needs Fixing (Priority Order)

#### 1. CRITICAL UX FIXES
- [ ] cursor-pointer on ALL clickable elements
- [ ] Touch targets minimum 44x44px with 8px spacing
- [ ] ARIA roles on div/span with onclick handlers
- [ ] Smooth transitions 150-300ms on all interactive elements
- [ ] Focus states visible for keyboard navigation

#### 2. LOADING & FEEDBACK
- [ ] Skeleton loading screens instead of "Cargando..."
- [ ] Toast notifications with better animation
- [ ] Button loading states (spinner + disabled while processing)
- [ ] Success/error feedback on all actions

#### 3. VISUAL POLISH
- [ ] Glassmorphism on modal overlays (backdrop-filter: blur)
- [ ] Card hover states with subtle elevation
- [ ] Better spacing and padding consistency
- [ ] Accent glow effects on primary actions
- [ ] Smooth page transitions between views

#### 4. AUTH SCREEN
- [ ] More polished login form with better spacing
- [ ] Google button with proper brand colors
- [ ] Input focus animations
- [ ] Password strength indicator on register

#### 5. COMPONENT REFINEMENTS
- [ ] Nav bar: active state animation, better touch targets
- [ ] Header: cleaner layout, timer animation
- [ ] Exercise cards: better visual hierarchy
- [ ] Modal: smoother open/close animations, glassmorphism
- [ ] Wizard: progress animation, better step transitions
